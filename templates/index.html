About This Project

Symptoms-Based Disease Prediction Using Hybrid Deep Learning

Project Overview

This project addresses a critical challenge in healthcare: accurate and timely disease diagnosis based on symptoms. Traditional diagnosis depends on clinical expertise which may not always be available, especially in under-resourced areas.

Our system uses a hybrid ensemble of 3 Deep Learning models (Dense NN, Conv1D, Attention) and 5 Machine Learning classifiers (Logistic Regression, Naive Bayes, Decision Tree, Random Forest, XGBoost) to analyze symptom patterns and predict diseases with high accuracy.

The ensemble approach ensures that predictions are context-aware and statistically robust by combining outputs from all 8 models via probability averaging, significantly reducing the influence of occasional errors from any single classifier.

Objectives & Motivation

Data Collection

Collecting and preparing symptom-based datasets from reliable medical repositories covering 773 diseases and 377 symptoms.

Hybrid Model Design

Designing an ensemble model incorporating both deep learning and classical ML algorithms for multi-angle symptom analysis.

Performance Evaluation

Evaluating performance with accuracy, precision, recall, and F1-score against standalone approaches to demonstrate improvement.

Web Deployment

Deploying through a Flask web application for easy real-time interaction by medical practitioners and individuals.
